# e2e scripts

These scripts test real behavior and are **not** part of `bun run check`. Most need a running app (`bun run dev`, or `bun run build && bun run start`) and some call paid providers. Run them one at a time, on purpose. Run commands are from the repo root; `<url>` is the app origin (the default port is in each script's header).

Columns come from reading each script and its header comment. "Providers" lists what the script can reach, directly or through the app. Cost: free = no paid calls; cents = a few model calls; dollars = media generation or realtime sessions; unknown = the script does not say.
